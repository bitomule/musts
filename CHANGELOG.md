# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

> **Pre-1.0:** minor versions may include breaking changes to the CLI surface,
> the extension protocol, or the `MUSTS.yml` format. Patch versions are
> bug-fix only.

## How this file is maintained

This changelog is generated by [`release-plz`](https://release-plz.dev/) from
Conventional Commits. Every push to `main` updates the rolling **release PR**
(`chore(release): vX.Y.Z`), which is the only place where the
`[Unreleased]` content gets promoted into a dated version section. Do not edit
this file by hand in feature PRs.

Each release section follows the [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
categories: **Added**, **Changed**, **Deprecated**, **Removed**, **Fixed**,
**Security**. Internal-only changes (refactors, CI, build tooling) are grouped
under **Internal** and may be omitted from release notes.
